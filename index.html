🏠 HomeGuard

A Raspberry Pi-based home network monitoring system that detects unknown devices, captures snapshots, and sends real-time alerts.


View on GitHub Installation Guide

⚡ Features

📡

Network Scanning

ARP scan every 30 seconds to detect all connected devices.

🔍

Unknown Detection

Flags unknown MAC addresses and starts a 2-minute alert timer.

📸

Camera Snapshots

Captures a photo using Pi Camera when an unknown device is detected.

🔴

SenseHAT Alert

Flashes the SenseHAT LED matrix red when an intruder is detected.

📱

Telegram Alerts

Sends real-time notifications to your phone via Telegram Bot API.

🌡️

Cloud Logging

Logs CPU temperature and device counts to ThingSpeak IoT platform.

📨

MQTT Publishing

Publishes scan events to HiveMQ Cloud via MQTT over TLS.

⚙️

Configurable Settings

Scan interval and thresholds editable via the web dashboard.

🗄️

SQLite Database

Stores all scan events and alerts locally in a SQLite database.

🌐

Web Dashboard

Flask web dashboard showing all devices, alerts, and settings.

⚙️

Auto-Start

Runs automatically on boot via systemd service.

🚀 Quick Start

Clone the repo and follow the installation guide:

git clone https://github.com/bounchun/HomeGuard.git
cd HomeGuard
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
sudo python3 app.py
